# Capstone Review Questions

1. What falsifiable performance claim does this project make?
2. Which evidence identifies the original bottleneck?
3. What variable changed, and what stayed fixed?
4. Why should the change affect the selected hardware metric?
5. Did kernel speed translate to end-to-end speed, and why?
6. What correctness and numerical risks were tested?
7. How would the result change on another architecture or workload shape?
8. What hardware change would best complement the software optimization?
